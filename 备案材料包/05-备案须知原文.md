# 备案须知原文摘录

专员问起来时可以直接引用。原文来源：宁波卓智备案说明页 + 雨云域名备案页。

## 一、通用流程（接入商原文）

1. 支持网站备案与 APP 备案。链接内容的必填项（网站备案信息采集表、APP 备案信息采集表）
   按备案内容选择填写；各省承诺书模板在页面下载（找不到就是不需要）；
   备案承诺书/授权书盖章或签名后按手印，拍成电子版。
2. 下载域名证书（图片即可，可在域名注册商处下载）。
3. 确认资料无误后，工作时间 QQ 私聊群内「备案专员」
   （QQ：196014279 周1-2 / 1374867266 周3-5）。
4. 提交后预计 7–20 个工作日通过。查询：https://beian.miit.gov.cn
5. 不明白的在**工作时间**私聊咨询备案专员。
6. 群内仅供临时交流，**请勿在群内发敏感个人信息和文件**。

### 注意事项（原文）

- 备案主体曾经备案过的域名，如果未注销，请确保能正常访问。
- 采集表中，备案域名的**备注内容不能和同主体曾经备案的备注内容一样**。
- **金融和教育业务和西藏区域暂不支持接入宁波区域备案。**
- 山东目前可提交备案。

## 二、内蒙古 · 企业备案（原文）

### 主体相关

1. 负责人需年满 18 周岁。
2. 主体负责人必须是法定代表人。
3. 无字号个体工商户需去工商局添加单位名称后再备案，无字号不能直接备案。

### 域名相关

- 域名所有者须与主办单位名称或法定代表人一致。

### 证件相关

1. **企业备案法定代表人身份证非本自治区，需提供法定代表人手持身份证以及营业执照。**
2. 事业单位、党政机关申请网站备案，均需向当地编制审核机构申请《网站名称审核表》后，
   提供原件彩色扫描件和组织机构代码等证件。
3. 涉及医院需上传营业执照、《医疗机构执业许可证》与《医疗广告审查证》。

### 变更相关

- 企业变更为企业只接受更名，需要同时附更名函；其他情况不允许变更主体。

## 三、通用采集表必填项（带 * 号）

### 主办单位信息

- 主办单位名称 *
- 主办单位性质 *
- 主办单位有效证件类型 *
- 主办单位有效证件号码 *
- 证件住所 *
- 主办单位通信地址 *

### 主体负责人基本情况

- 姓名 *（需填写法人信息）
- 有效证件类型 *
- 有效证件号码 *
- 身份证有效期 *
- 移动电话号码 *
- 应急联系电话 *（不能与主体负责人或网站负责人电话相同）
- 电子邮箱 *

### ICP 备案网站信息

- 网站名称 *
- 网站域名 *（不加 www.）
- 网站首页网址 *（不加 http://）
- 网站服务内容 *
- 备注（网站运营内容）*

### 网站负责人基本情况

- 姓名 / 证件类型 / 证件号码 / 身份证有效期 / 移动电话 / 应急联系电话 / 电子邮箱 *

### ICP 备案网站接入信息

- 网站 IP 地址 *
- 网站接入方式 *
- 服务器放置地 *

> 采集表原注：凡带 * 号的都是必填项，没带 * 号的可填可不填。

## 四、审核归属

- **审核管局 = 内蒙古**（按主体注册地）
- **接入地 = 浙江省宁波**（按服务器放置地）
- 宁波只是递材料的一方，真正的批复权在内蒙古通信管理局

这一条常被搞反。如果专员说「浙江管局怎么怎么样」，可以对照确认一下。
