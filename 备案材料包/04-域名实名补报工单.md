# 域名实名补报工单（复制去发雨云）

这是整件事的**唯一硬阻塞**。不发这一单，后面所有材料都用不上。

## 背景（你只需要知道这三点）

1. 雨云后台「我的模板」显示：初审通过、实名成功、所有人 = 内蒙古晟陟科技有限公司
2. 但工信部域名实名核验库查不到这个域名，备案提交时校验失败
3. 雨云是渠道，真正的注册商是**西部数码**（成都西维数码，IANA 1556），补报动作在西部数码

所以工单不能写「帮我重新上报」——要写「协调上游注册商补报」。

## 工单正文

```text
标题：域名 xiaoyuanbang.top 实名成功但工信部核验库无记录，请协调上游注册商补报

你好。

我的域名 xiaoyuanbang.top 在贵平台管理，ID 20341，可确认：
- 模板 ID 2659488，初审状态「初审通过」，实名状态「实名成功」
- 域名所有人：内蒙古晟陟科技有限公司
- WHOIS 显示注册商为成都西维数码科技有限公司（西部数码，IANA ID 1556）
- 域名状态 ok，有效期至 2027-10-27

但该域名在工信部域名实名核验库中查询不到，导致腾讯云 ICP 备案被驳回。
备案主体：内蒙古晟陟科技有限公司
腾讯云备案订单号：30179388576817021
驳回原文：【请粘贴腾讯云驳回的完整文字】

我计划在贵司宁波接入通道提交 ICP 备案，域名实名不入库就无法提交，
请协助处理以下 4 项：

1. 请核实该域名在工信部域名实名核验库中的实际状态：是否存在记录？
   记录中的实名主体名称是什么？
2. 如实名成功但尚未上报工信部，请协调西部数码补报，并提供补报时间与回执。
3. 如库中记录的实名主体不是「内蒙古晟陟科技有限公司」（例如为代持主体），
   请说明原因并给出修正方案与所需材料。
4. 请勿仅回复「域名已实名」。实名成功与已上报工信部是两件事，
   我需要的是工信部库的查询结果。

时限：请在 3 个工作日内给出上述 4 项的书面答复。
若确认贵司无权补报，请书面告知，并说明应由哪个主体向谁发起补报。
```

## 关键改动：为什么加「我计划在贵司宁波接入通道提交」

这是这次的核心策略。

- 只说「域名查不到」→ 你在他眼里是**域名售后**，优先级最低，回一句「已实名」就关单
- 加上「我要在你们这备案」→ 你变成**潜在备案客户**，域名不通他就赚不到这笔钱

同一个问题，推动力完全不同。第 4 项的「不要只回已实名」也要留着，
因为客服的标准动作就是复制那句。

## 跟进节奏

| 时间 | 动作 | 判断标准 |
|---|---|---|
| D0 今天 | 发工单，附截图 | 拿到工单号 |
| D+1 | 无实质答复 → 升级主管/技术 | 是否给出「库中状态」或「补报时间」 |
| D+3 | 仍未补报 → 要求书面说明责任方 | 是否承认无权补报 |
| D+3 | 同步在 QQ 群问备案专员一句 | 备案专员比域名客服更懂这套流程 |
| D+5～D+7 | 自己用腾讯云域名校验复验 | 报错消失即通过 |

## 你要附的三张截图

1. 雨云 → 域名管理 → 我的模板（带「初审通过 / 实名成功」两列那张）
2. 雨云 → 域名管理 → 域名详情（ID 20341、所有人、有效期）
3. 腾讯云备案订单的驳回页面（关于域名那条）

第 1 张最有说服力：它证明实名走了，问题在上报环节，客服没法含糊过去。

## 如果彻底无解

域名 2026-10-27 注册，gTLD 转出受 ICANN 60 天锁限制，**最早 2026-12-26 才能转出**。
在那之前只能靠补报解决，转出不是备选方案。
