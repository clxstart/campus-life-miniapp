# 备注文案（网站运营内容）

采集表「备注（网站运营内容）」直接抄一段。内蒙古要求选「其他」时必须写备注，
所以这段不只是补充说明，是**必填项**。

## 选哪一段

### 主选：A（最稳，弱化场景）

```
本网站为内蒙古晟陟科技有限公司自研互联网产品的配套信息展示站点，向注册用户提供
社团活动信息、生活服务信息、二手闲置信息的展示与查询服务，不含新闻、出版、教育、
培训、医疗、金融、电商交易等需前置审批的内容。
```

### 备选：B（想点出用户群体时用）

```
本网站为内蒙古晟陟科技有限公司面向高校学生群体的生活服务类产品配套站点，
内容为社团活动、生活服务与二手闲置信息展示，不含课程教学、培训辅导、升学考试等
教育类内容，不涉及新闻、出版、医疗、金融、电商交易。
```

### 最短：C（表格空间不够时）

```
公司产品配套信息展示站点，内容为生活服务类信息，不涉及前置审批内容。
```

建议用 **A**。它把功能说清楚了（审核方要的就是这个），但没有给出任何可以被归为教育业务的抓手。

## 为什么这么写

宁波接入商的原文限制是：

> 金融和教育业务和西藏区域暂不支持接入宁波区域备案。

「校园帮」这个名字 + 课表功能，在审核眼里很容易等于教育。所以：

- **服务名称**用「晟陟科技」，不出现「校园」
- **服务内容**选「其他」
- **备注**只描述业务形态（社团、生活服务、闲置信息），不描述使用场景（校园、学生、课程）

课表功能如果一定要提，写成「信息展示」，**不能**写成「课程管理」「选课」「成绩查询」。
一个词的差别，审核看到的是两种不同的业务性质。

## 禁用词表（写进备注前逐条搜一遍）

| 禁止出现 | 替换成 |
|---|---|
| 教育、教育培训、校外培训、培训 | 直接不提 |
| 课程、课表、选课、成绩、教学、辅导、升学、考试、学习 | 信息展示 / 信息服务 |
| 新闻、出版、视听、影视 | 直接不提 |
| 金融、理财、支付、借贷、投资 | 直接不提 |
| 医疗、药品、问诊 | 直接不提 |
| 论坛、社区、交流（可能触发前置审批） | 信息展示 |

> 「社区」这个词各省口径不一，有的要求电子公告服务审批。A 版文案里刻意没用它。

## 另一条容易被忽略的规则

接入商原文：

> 采集表中，备案域名的备注内容不能和同主体曾经备案的备注内容一样。

如果内蒙古晟陟科技有限公司名下已有其他备案域名，**这段备注必须重写**，
不能复制旧备案里那段。先查一次主体已备案情况（腾讯云「验证备案类型」可看）。
