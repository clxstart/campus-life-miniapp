# 校园生活微信小程序

这是一个可以直接导入微信开发者工具运行的原生微信小程序项目。首页按照提供的参考图实现，发现、发布、消息、聊天和个人中心使用同一套校园清新视觉系统。

## 运行方法

1. 解压项目压缩包。
2. 打开微信开发者工具。
3. 选择“导入项目”。
4. 选择本文件夹 `campus-life-miniapp`。
5. AppID 可以使用测试号，或者将 `project.config.json` 中的 `touristappid` 换成自己的小程序 AppID。
6. 点击“编译”。

## 已实现内容

- 自定义顶部导航和微信胶囊避让
- 学校选择
- 搜索输入
- 通知入口
- 外卖、二手、论坛、兼职和活动卡片
- 学习专区（作业答疑 / 论文指导 / 学习好物）
- 校园推荐和广告卡片
- 固定底部导航
- 发现页动态流、热门话题、筛选、关注和点赞
- 完整发布表单、图片选择、本地发布记录
- 消息列表、通知列表和可发送消息的聊天页
- 个人资料、校园身份、常用功能和设置入口
- 本地图片和图标，不依赖网络资源
- 独立 mock 数据层和接口适配层

## 参考视口

设计参考图为 672×1242px。截图验收建议使用接近 375×693 的逻辑视口，并关闭微信开发者工具的手机外框。
