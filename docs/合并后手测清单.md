## 已知限制（答辩时要说明）

1. **支付为模拟**：`wxpay.enabled=false`，走 `simulated` 分支，不产生真实扣款
2. **退款为模拟**：`campus.wxpay.enabled=false`，拒单时退款记录写入但无真实资金流转
3. **真实联调需**：微信商户号、证书私钥、APIv3 密钥、公网 HTTPS 回调地址
4. **小程序端需开发者工具**：命令行无法验证点击交互
