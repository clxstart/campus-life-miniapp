### T16.3 伪造 token
```js
wx.request({
  url: 'http://127.0.0.1:8080/api/users/1/profile',
  header: { Authorization: 'Bearer forged.invalid.token' },
  success: r => console.log(r.statusCode, r.data)
```

## 十八、常见问题

### 页面白屏 / 报「编译 .wxml 文件错误」
- 看控制台报的是哪个文件
- 常见原因：`wx:if` 和 `wx:elif` 之间插了别的节点
- 自查：`python tests/validate_project.py` 能查出来

### 数据不对 / 显示的是旧数据
- 清缓存：工具栏 → 清缓存 → 全部清除
- 或看后端是否真的在跑

### 控制台一片红色 ERR_CONNECTION_REFUSED
- **后端没启动**。这是正常的离线兜底路径，页面仍可用
- 启动后端后自动恢复

### 上传图片失败
- 检查 `backend/uploads/` 目录是否存在
- 检查后端日志有没有报错

### 后端启动报「找不到符号 getXxx()」
- JDK 23+ 的注解处理问题
- 确认启动命令带了 `-P "!jdk-1.8"`
- 详见 `README_BACKEND.md` 的「编译注意」章节
