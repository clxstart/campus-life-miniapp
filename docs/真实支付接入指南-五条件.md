# 真实微信支付接入指南（五条件逐步版）

> 用途：把"现在只能模拟支付"变成"能真收钱"，按本文一步步办即可
> 编写时间：2026-10-26
> 当前状态：`wxpay.enabled=false`，走模拟支付，一分钱不真收

---

## 零、先看懂：为什么现在不能真支付

代码是写好的（下单、支付、退款、对账定时任务都在），但缺的是**资质和密钥**，不是代码。

小程序里点"支付"时，后端做的是这件事：

```java
if (!properties.isEnabled()) {
    // 支付未启用 → 直接标记已付款（模拟）
    markPaid(order, "SIM-" + order.getOutTradeNo(), ...);
}
```

`properties.isEnabled()` 读的是 `wxpay.enabled`，现在是 `false`。所以它走上面那条路，订单瞬间变「已支付」，微信那边**完全没参与**。

要让它走真实支付，需要把下面 5 个条件全部凑齐。

---

## 条件 1：真实小程序 AppID（替换 touristappid）

### 现在是什么

`project.config.json` 里是 `"appid": "touristappid"` —— 这是微信开发者工具的**游客模式**，只能本地预览，**不能调支付、不能上传代码、不能发布**。

### 你需要做什么

1. 打开 https://mp.weixin.qq.com/ 注册小程序账号
2. 主体类型选**企业**（个体户也可以，见下方说明）
3. 注册完成后，在「开发 → 开发管理 → 开发设置」里拿到 **AppID**

### 个人能不能申请？

| 主体 | 能否开通支付 | 说明 |
|---|---|---|
| 个人 | ❌ 不能 | 个人主体小程序**无法**申请微信支付 |
| 个体工商户 | ✅ 能 | 有营业执照即可，办理成本低（几百元） |
| 企业 | ✅ 能 | 标准路径 |

> **这是最关键的一条**：如果你是个人身份，必须先去办个体工商户执照，否则后面全免谈。

### 成本与时间

- 小程序注册：免费，1-3 天审核
- 个体工商户执照：约 200-500 元，3-7 天
- 微信认证：**300 元/年**（小程序认证费，支付需要）

## 条件 2：微信支付商户号（mch-id）

### 是什么

商户号是你在微信支付体系里的"账号"，形如 `1600000000`。它和小程序 AppID 是**两个独立的东西**，需要**关联绑定**。

### 办理步骤

1. 打开 https://pay.weixin.qq.com/ → 「接入微信支付」
2. 选择「普通商户」→ 提交资料（营业执照、法人身份证、银行账户）
3. 审核通过后拿到**商户号**
4. 在商户平台「产品中心 → AppID 账号管理」里**关联你的小程序 AppID**
5. 回到小程序后台「微信支付」里**确认关联**

> 第 4、5 步必须**双向确认**，只做一边绑定不生效。这是最常见的坑。

### 成本与时间

- 开通免费，1-5 天审核
- 费率：**0.6%**（教育/校园类可申请优惠费率，需额外提交材料）

## 条件 3：三件套密钥（APIv3 密钥 + 证书序列号 + 私钥文件）

这是最容易卡住的地方，三样东西**缺一不可**。

### 3.1 APIv3 密钥（32 位）

- 位置：商户平台 →「账户中心 → API 安全 → APIv3 密钥」
- 自己设置，**必须是 32 位**（字母数字混合）
- ⚠️ 设置后**无法查看**，只能重设。**立刻存进密码管理器**

对应配置项：`WXPAY_API_V3_KEY`

### 3.2 商户证书（序列号 + 私钥）

- 位置：商户平台 →「账户中心 → API 安全 → 申请 API 证书」
- 用「证书工具」生成，会得到两个文件：
  - `apiclient_cert.pem`（证书）
  - `apiclient_key.pem`（**私钥，这是最关键的**）
- 证书详情里能看到**证书序列号**（一长串十六进制）

对应配置项：
- `WXPAY_CERT_SERIAL_NO` = 序列号
- `WXPAY_PRIVATE_KEY_PATH` = 私钥文件在服务器上的**绝对路径**

### 私钥文件放哪

```bash
# 放到服务器上，权限收紧（只有运行后端的用户能读）
mkdir -p /opt/campus/certs
cp apiclient_key.pem /opt/campus/certs/
chmod 600 /opt/campus/certs/apiclient_key.pem
chown campus:campus /opt/campus/certs/apiclient_key.pem

export WXPAY_PRIVATE_KEY_PATH=/opt/campus/certs/apiclient_key.pem
```

> ⚠️ **私钥绝不能提交到 Git**。项目的 `.gitignore` 已经忽略 `*.pem`，但仍要自己确认。

## 条件 4：公网 HTTPS 回调地址

### 为什么必须有

微信支付完成后，微信服务器会**主动 POST** 到你配置的地址通知"这笔付成功了"。这个地址必须：

| 要求 | 说明 |
|---|---|
| **公网可访问** | `127.0.0.1` / 内网 IP 一律不行 |
| **HTTPS** | 必须是有效证书，自签名不行 |
| **80/443 端口** | 微信只支持 80/443 |
| **不能带参数** | 只能是纯路径 |

### 你需要什么

1. **一个已备案的域名**（国内服务器必须备案）
2. **SSL 证书**（免费可用 Let's Encrypt）
3. **Nginx 反代到后端 8080**

示例 Nginx 配置：

```nginx
server {
    listen 443 ssl;
    server_name api.你的域名.com;

    ssl_certificate     /etc/letsencrypt/live/api.你的域名.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.你的域名.com/privkey.pem;

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

对应配置项：
- `WXPAY_NOTIFY_URL` = `https://api.你的域名.com/api/pay/notify`
- `WXPAY_REFUND_NOTIFY_URL` = `https://api.你的域名.com/api/pay/refund/notify`

### 成本与时间

- 域名：约 30-60 元/年
- 备案：免费，**7-20 天**（这是最耗时的环节）
- 证书：Let's Encrypt 免费，5 分钟

> ⚠️ **备案是最长的等待**。建议先启动备案，其他条件并行办。

## 条件 5：小程序后台配置合法域名

### 做什么

小程序默认只能请求**已配置的 HTTPS 域名**。不配的话，真机上所有接口都会失败。

位置：小程序后台 →「开发 → 开发管理 → 开发设置 → 服务器域名」

| 类型 | 填什么 |
|---|---|
| request 合法域名 | `https://api.你的域名.com` |
| uploadFile 合法域名 | `https://api.你的域名.com` |
| downloadFile 合法域名 | `https://api.你的域名.com` |

同时改小程序代码里的后端地址：

```js
// utils/config.js
const ENV = 'prod'   // 从 'dev' 改成 'prod'
const ENDPOINTS = {
  prod: {
    api: 'https://api.你的域名.com/api',
    asset: 'https://api.你的域名.com'
  }
}
```

## 配好之后怎么验证（分三步，别一上来就真付钱）

### 第一步：验证配置读对了（不花钱）

```bash
export WXPAY_ENABLED=true
export WXPAY_APP_ID=wx真实appid
export WXPAY_MCH_ID=你的商户号
export WXPAY_CERT_SERIAL_NO=证书序列号
export WXPAY_API_V3_KEY=32位密钥
export WXPAY_PRIVATE_KEY_PATH=/opt/campus/certs/apiclient_key.pem
export WXPAY_NOTIFY_URL=https://api.你的域名.com/api/pay/notify
export WXPAY_REFUND_NOTIFY_URL=https://api.你的域名.com/api/pay/refund/notify

# 用 prod profile 启动（会强制校验配置完整性，缺一个直接启动失败）
java -jar campus-life-api.jar --spring.profiles.active=prod
```

**预期**：启动成功，日志里**没有** `模拟支付生效` 字样。

如果启动失败并报"商户号/证书序列号/私钥路径未配置"，说明某项没读到 —— 检查环境变量是否在当前 shell 生效。

### 第二步：下 1 分钱测试单（花 0.01 元）

⚠️ **不要用 1 元测试，直接下最小金额**。微信支付最低 0.01 元。

1. 小程序里下一个外卖订单，把商品价格改成 **0.01 元**（或后台临时改价）
2. 点支付 → 应弹出**真实微信支付界面**
3. 用你自己的微信付款 0.01 元
4. 检查三件事：
   - 小程序里订单变「已支付」
   - 管理端 `#/orders` 能看到这笔（页面会自动刷新）
   - 数据库 `payment_record` 表里 `verified=1`、金额 1 分、`transaction_id` 非空

**如果付款成功但订单没变**：说明回调没通。去商户平台查「交易」页确认是否成功，再看后端日志有没有收到 `/api/pay/notify`。

### 第三步：测退款

1. 管理端对那笔 0.01 元订单点退款
2. 检查：微信应退回 0.01 元；`refund_record` 表状态变 `success`

> 退款走的是官方 APIv3 SDK，配置和支付共用同一套密钥（这个之前已经合并过，不会再出现"能付不能退"）。

## 上线前必须确认的安全项

| 检查 | 为什么 | 怎么查 |
|---|---|---|
| `campus.pay.simulate` 必须是 `false` | 否则模拟支付可能被误用 | prod profile 已强制拒绝，但确认一下 |
| `WXPAY_API_V3_KEY` 是 32 位 | 长度不对 SDK 直接报错 | `echo -n $WXPAY_API_V3_KEY \| wc -c` 应为 32 |
| 私钥文件权限 600 | 泄露等于别人能替你退款 | `ls -l` 确认 |
| 私钥不在 Git 里 | 同上 | `git log --all -- '*.pem'` 应为空 |
| 回调地址用 HTTPS | HTTP 微信直接拒绝 | 浏览器打开应显示证书有效 |
| 金额用「分」计算 | 浮点会算错钱 | 检查代码里 `payAmountCents` |

## 我的建议：答辩阶段要不要接？

**不建议接。** 三个理由：

1. **时间成本**：备案 7-20 天，是硬等待。答辩前时间紧的话这是最大的不确定性。
2. **资质门槛**：个人主体直接不行，要办执照。
3. **演示效果差不多**：模拟支付能完整演示「下单 → 支付 → 状态流转 → 退款 → 对账」全链路，老师看的是**系统设计**，不是"真的收到钱"。

**替代方案**：答辩时主动说明"支付已按微信官方 APIv3 实现完整链路，因资质原因当前使用模拟模式，切换只需配置 5 个环境变量"，然后把本文档作为交付物之一 —— 这比硬接真实支付更稳妥，也显得你清楚边界在哪。
