## 四、素材渲染流程（Kenney 部分，供复现）

如需重新生成方块宠物图：

```bash
# 1. 解压 Kenney Cube Pets
# 2. 把 GLB 模型与 Textures 放入 _assets/render/models/
# 3. 启动本地服务器
cd _assets/render && python -m http.server 8899

# 4. 运行批量渲染（Chrome DevTools Protocol + three.js）
node render-pets.js
```

输出为 512×512 带 alpha 的 PNG。渲染脚本：`_assets/render/render-pets.js`。
