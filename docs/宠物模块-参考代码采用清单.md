## 一、UI 组件库

| 项 | 内容 |
|---|---|
| **来源** | TDesign 微信小程序版 `tdesign-miniprogram` |
| **文档** | https://tdesign.tencent.com/miniprogram/overview |
| **仓库** | https://github.com/Tencent/tdesign-miniprogram |
| **复用什么** | Button / Popup / Tabs / Input / Toast / Dialog 的组件与事件约定；主题变量（CSS Variables）覆盖配色 |
| **改造什么** | 通过 `--td-*` 变量把默认蓝替换为森林绿主题；不直接改 `node_modules` |
| **版本锁定** | 安装后固定在 `package.json` 的精确版本，见实际安装记录 |
| **约束** | 原生小程序，**不装** TDesign 的 Vue / React / uni-app 版本 |
| **共存策略** | 宠物相关新页面只用 TDesign Popup；项目原有的 `components/ui-popup` 保留给其他既有模块，**不得在同一页面混用两套弹层** |

## 二、Canvas 2D

| 项 | 内容 |
|---|---|
| **来源** | 微信官方示例 https://github.com/wechat-miniprogram/miniprogram-demo |
| **文档** | https://developers.weixin.qq.com/miniprogram/dev/component/canvas.html |
| **复用什么** | Canvas 2D 节点查询（`createSelectorQuery` + `.fields({node:true,size:true})`）、`dpr` 像素比适配、`requestAnimationFrame` 动画循环写法 |
| **改造什么** | 封装为独立自定义组件 `pet-canvas`，在**组件内部作用域**查询节点；不使用旧版 `CanvasContext`；命中检测把触摸坐标换算到宠物逻辑坐标；用 `lifetimes.detached` 销毁 |
| **不搬什么** | 官方 demo 的云开发架构（本项目后端仍是 Java/Spring Boot）；浏览器里的 `window`/`document`/DOM 查询 |

## 三、猫咪分层捏脸

| 项 | 内容 |
|---|---|
| **来源** | https://github.com/vicalejuri/cat-avatar-generator |
| **参考页** | https://www.peppercarrot.com/extras/html/2016_cat-generator/ |
| **复用什么** | **仅复用“分层部件按编号组合”的思路** 与“固定输入产生固定外观”的确定性逻辑 |
| **改造什么** | 原项目的 DOM 拼图改为小程序 Canvas 绘制；手动捏脸保存**明确的部件编号**（不只是种子）；需要服务端组合时用 Java 实现 |
| **不做什么** | 不使用其 PHP / Next.js 作为生产服务；不依赖 Vercel 第三方接口；**不声称**它自带动态全身/衣柜/小程序编辑器 |
| **美术处理** | 本项目**另行制作统一画风的原创部件**，不把原项目猫头画风与全身宠物强行拼接 |
| **许可** | 若实际使用其美术资源：按其 CC BY 4.0 要求署名 + 来源 + 许可链接 + 修改说明。**本项目当前采用原创部件，不使用其美术文件** |

## 八、落地决定（本轮实施时确认）

| 决策点 | 决定 | 理由 |
|---|---|---|
| 组件库共存 | 新增 TDesign，宠物新页专用 | 用户已确认；旧页不迁移，避免大范围回归 |
| 宠物美术 | 原创 Canvas 矢量绘制部件 | 满足“不把不同画风强行拼接”且交付可控，无需外部下载 |
| 破壳动画 | 优先 Canvas 实现 | 当前无可用 Lottie JSON 资源，按“不引入空依赖”执行 |
| 外观存储 | 数据库存**部件编号** | 满足“手动捏脸必须保存明确部件编号” |
| 派遣进度 | 服务端存 `start_at` / `duration` / `claimed` | 满足“关闭小程序不丢进度、不错过扣奖励” |
