## 九、后端接口测试

可直接用 curl 或 Postman 测试。

### 9.1 宠物接口

```bash
# 读取外观
curl "http://127.0.0.1:8080/api/pet/appearance?userId=1"

# 保存外观
curl -X PUT "http://127.0.0.1:8080/api/pet/appearance" \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"species":"cat","tint":"natural","accessory":"scarf","moodTag":"calm"}'

# 衣柜
curl "http://127.0.0.1:8080/api/pet/wardrobe?userId=1"

# 派遣状态
curl "http://127.0.0.1:8080/api/pet/dispatch?userId=1"

# 开始派遣
curl -X POST "http://127.0.0.1:8080/api/pet/dispatch/start" \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"code":"task_library"}'
```

## 十、已知限制

测试时以下项属**预期行为**，不是 bug：

| 项 | 说明 |
|---|---|
| 支付为模拟 | `wxpay.enabled=false`，走模拟分支，不产生真实扣款 |
| 退款为模拟 | `campus.wxpay.enabled=false`，拒单只记录退款单 |
| 微信内容安全未启用 | 未配 `appid/secret`，审核走本地敏感词 |
| AI 对话为 Mock | 消息标注「演示数据」，非真实模型 |
| 宠物形象固定 | 小橘猫为成套贴图，无法更换物种/色调 |
| 宠物无配饰 | 引擎不含配饰图层，收藏仅记录不穿戴 |
| `touristappid` 弹窗 | 游客模式提示，配正式 AppID 消除 |
| 小程序真机未验证 | 无真实 AppID，仅开发者工具内验证 |
