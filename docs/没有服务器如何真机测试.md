# 没有服务器怎么真机测试

> 适用：手头只有一台电脑 + 一部手机，没有云服务器、没有备案域名
> 编写时间：2026-10-27
> 结论先说：**完全可以在真机上测**，有三条路，按你愿不愿意花钱/花时间选

---

## 零、先搞清楚：真机测试到底卡在哪

微信小程序的真机**不允许请求 `http://` 和 IP 地址**，只允许：

- `https://` 且域名已在小程序后台「request 合法域名」里登记
- 或者：在开发者工具里勾选「**不校验合法域名**」，然后**用工具预览/真机调试**

所以卡点是"域名 + HTTPS"，不是"服务器"。下面三条路分别绕过它。

---

## 方案 A：开发者工具「真机调试」（推荐，零成本）

### 原理

开发者工具的「真机调试」模式，手机端跑的是**工具下发的调试包**，这个模式**跳过域名校验**。所以你的手机能直连电脑上的后端。

### 步骤

**1. 让后端监听所有网卡**

默认后端只监听 `127.0.0.1`，手机访问不到。改成 `0.0.0.0`：

```bash
# 方式一：命令行参数
cd backend
mvn spring-boot:run -Dspring-boot.run.arguments=--server.address=0.0.0.0

# 方式二：改配置（推荐，一次改好）
# 在 application-dev.yml 里加：
# server:
#   address: 0.0.0.0
```

**2. 查出电脑的局域网 IP**

```powershell
# Windows
ipconfig | Select-String -Pattern 'IPv4'
# 找 192.168.x.x 或 10.x.x.x 那种（不是 127.0.0.1）
```

假设拿到 `192.168.1.23`。

**3. 改小程序的后端地址**

```js
// utils/config.js
const ENV = 'dev'

const ENDPOINTS = {
  dev: {
    // 把 127.0.0.1 换成你的局域网 IP
    api: 'http://192.168.1.23:8080/api',
    asset: 'http://192.168.1.23:8080'
  },
  // ...
}
```

**4. 放行防火墙**

```powershell
# 以管理员身份运行 PowerShell
New-NetFirewallRule -DisplayName "campus-backend-8080" -Direction Inbound `
  -Protocol TCP -LocalPort 8080 -Action Allow
```

**5. 先用手机浏览器验证通不通**

手机连**同一个 WiFi**，浏览器打开：

```
http://192.168.1.23:8080/api/schools
```

看到 JSON 就说明网络通了。**这一步不通，后面全白搭**，先解决它（见文末排查表）。

**6. 开发者工具里真机调试**

1. 微信开发者工具 → 右上角「**预览**」或「**真机调试**」
2. 手机扫码
3. **关键**：工具右上角「详情 → 本地设置」里勾选「**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**」
4. 手机上打开，看数据是否正常加载

### 优点 / 缺点

| 优点 | 缺点 |
|---|---|
| 零成本、5 分钟配好 | 手机必须和电脑**同一个 WiFi** |
| 能真机测所有交互 | 电脑关机/断网就不能测 |
| 能看真机日志（真机调试面板） | 不能给**别人**（老师/同学）扫码体验 |

> **答辩现场如果要用手机演示**：这个方案有风险（现场 WiFi 未必允许设备互访）。建议提前用方案 B 或 C 准备一个外网地址兜底。

---

## 方案 B：内网穿透（免费可用，能给外人扫）

### 原理

用内网穿透工具把「你电脑的 8080」映射成一个**公网 https 地址**，手机和任何人都能访问。

### 常见工具对比

| 工具 | 免费额度 | 是否需要备案 | 稳定性 | 备注 |
|---|---|---|---|---|
| **cpolar** | 有免费隧道（随机域名，会变） | 不需要 | 一般 | 国内可用，中文文档 |
| **natapp** | 免费隧道（域名固定但随机） | 不需要 | 一般 | 国内，需实名 |
| **ngrok** | 免费（域名随机，每次变） | 不需要 | 较好 | 国外，偶尔被墙 |
| **frp（自建）** | 需要一台有公网 IP 的机器 | — | 取决于机器 | 你已经有服务器的话最灵活 |
| **cloudflared tunnel** | 免费 | 不需要 | 好 | 需要 Cloudflare 账号 |

### 以 cpolar 为例（具体步骤各工具类似）

```bash
# 1. 下载并注册 cpolar，本地启动
cpolar http 8080

# 2. 它会输出一个地址，形如：
#    Forwarding  https://a1b2c3d4.r3.cpolar.cn -> http://localhost:8080

# 3. 把小程序地址改成这个 https 地址
#    utils/config.js → api: 'https://a1b2c3d4.r3.cpolar.cn/api'
```

**4. 小程序后台加白名单**（否则真机还是报错）

微信公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名：

```
request 合法域名：https://a1b2c3d4.r3.cpolar.cn
uploadFile 合法域名：https://a1b2c3d4.r3.cpolar.cn
```

> ⚠️ 免费版隧道域名**重启就会变**，每次变都要改 config + 改白名单，很烦。如果只是临时测一次可以接受。

### 优点 / 缺点

| 优点 | 缺点 |
|---|---|
| 能给任何人扫码（老师、同学） | 免费版域名会变 |
| 不需要服务器、不需要备案 | 免费版有带宽/连接数限制 |
| 手机不需要同 WiFi（4G 也能测） | 稳定性一般，演示时可能抽风 |

## 方案 C：临时用你已有的服务器（如果你有）

你之前提过有一台 `16h16g` 的服务器。如果有，这是**最稳的方案**：

```
服务器上跑：MySQL + 后端(8080) + Nginx(443)
域名：用服务器已有的域名（如果已备案）或临时用 IP + 自签证书
```

但要注意：

| 事项 | 说明 |
|---|---|
| 小程序**不接受 IP + 自签证书** | 必须真域名 + 有效证书 |
| 域名没备案 | 国内服务器 80/443 会被拦，除非用香港/海外机器 |
| 已有域名但没备案 | 同上 |

所以方案 C 的前提是「**有一个已备案的域名**」。没有的话还是走 A 或 B。

---

## 三条路怎么选

| 你的情况 | 推荐 |
|---|---|
| 只自己测、手机和电脑同 WiFi | **方案 A**（5 分钟） |
| 要给老师/同学扫码体验 | **方案 B**（内网穿透） |
| 有已备案域名 + 服务器 | **方案 C**（最稳） |
| 答辩现场 | **B 或 C**（现场 WiFi 不可控） |

## 真机上最容易出问题的 6 个地方

按我踩过的顺序排：

### 1. 手机浏览器打不开 `http://IP:8080/api/schools`

| 可能原因 | 怎么查 |
|---|---|
| 后端只监听 127.0.0.1 | `netstat -ano \| findstr :8080`，看是 `0.0.0.0:8080` 还是 `127.0.0.1:8080` |
| Windows 防火墙拦了 | 见上面「放行防火墙」 |
| 手机和电脑不在同一网段 | 手机看 WiFi 详情里的 IP，前三段应和电脑一致 |
| 电脑连的是「访客网络」 | 访客网络通常隔离设备，换主网络 |

### 2. 浏览器能打开，小程序里却空白

99% 是「不校验合法域名」没勾。检查：开发者工具 → 详情 → 本地设置。

### 3. 图片全部裂开

图片地址是 `http://127.0.0.1:8080/uploads/xxx`（后端返回的绝对地址），手机上 `127.0.0.1` 指向手机自己。

**修法**：后端配置里改上传基址：

```yaml
campus:
  upload:
    base-url: ${CAMPUS_UPLOAD_BASE_URL:http://192.168.1.23:8080}   # 换成局域网 IP
```

### 4. 登录失败 / 一直提示请先登录

- 手机端 `dev-login` 可能被关：确认后端 `campus.wx.appid` 为空（未配微信登录时才允许 dev-login）
- 或者 token 存不下来：真机调试模式下 storage 正常，但**预览模式**下有些接口受限

### 5. 支付测不了

真机 + `touristappid` 调不了微信支付。当前是模拟支付，点支付会直接变「已支付」——这是预期行为，不是 bug。

### 6. 上传图片失败

- 单文件限 5MB，手机拍的照片常超过
- 检查 `uploadFile 合法域名` 是否配置（方案 B/C 需要）

## 附：本机自测的最快路径（不用手机）

如果只是想验证功能对不对，**根本不用真机**：

| 测什么 | 用什么 |
|---|---|
| 接口对不对 | `curl` 或 Postman 直接打 8080 |
| 管理端页面 | 浏览器开 `localhost:5180` |
| 小程序页面 | 微信开发者工具**模拟器**（够用，只是不是真机） |
| 小程序真机特有行为 | 只有这时才需要上面的方案 A/B/C（如：真机手势、性能、扫码、支付） |

**答辩演示**其实用「开发者工具 + 投屏」比真机更稳——不会因为 WiFi 或手机没电翻车。

---

## 一句话总结

**没有服务器完全能测**：同 WiFi 用方案 A（改后端监听地址 + 改 config 里的 IP + 勾不校验域名），三处改动，5 分钟。
要给外人扫码就上内网穿透（方案 B），但免费版域名会变，演示前记得重新配白名单。
