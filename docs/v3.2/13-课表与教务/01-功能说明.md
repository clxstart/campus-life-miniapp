## 一、这个功能解决什么问题

大学生每天要看"第几周、星期几、第几节、在哪上课"。这个功能给每个学生一份可自己维护的课表：

1. **学期**是课表的挂载点：一份课表属于某个学期，学期有开学日、结束日、期中、期末四个日期锚点；"现在是第几教学周"由开学日推算。
2. **课程**由学生自建，或由管理员**用 CSV 批量导入**（各校教务系统没有公开接口，这是官方给定的替代方案）。
3. **作息时间**三级优先：学生本地覆盖 > 学校配置 > 内置默认（08:00/10:00/14:00/16:00/19:00 五个大节）。
4. **校历**（calendar_event）曾经存在，**已下线**，接口与后台页面都已删除。

## 二、用户看到的样子（小程序端）

路径（查看课表）：

1. 底部导航或入口 → `pages/timetable/timetable`（`app.json:17` 已注册）；
2. `onLoad` 同时做三件事：读本地作息、拉学校作息（学生没自定义时才拉）、`GET /api/timetable`（`pages/timetable/timetable.js:63-69`）；
3. 后端返回 `termInfo` + `week` + `courses`；前端再按周过滤一次（`timetable.js:101-110`）；
4. 渲染 5 行（五个大节）× 7 列（周一~周日）的网格（`timetable.js:112-114`）；
5. 表头显示"X月X日 周X · 第N教学周"（`timetable.js:120`）；
6. 切周：`switchWeek` 传周次重新请求（`timetable.js:126-131`）。

路径（自建课程）：

1. 点空格子 → 打开表单（`timetable.js:135-140`）；
2. 填课程名 + 教室 → `POST /api/timetable/courses`（`timetable.js:155-159`）；
3. 成功后就地插入网格，不整页重拉（`timetable.js:163-165`）；
4. 点已有课程 → 确认弹窗 → `DELETE /api/timetable/courses/{id}`（`timetable.js:172-193`）。

路径（改作息）：点时间 → 本地存 `campus_period_times`（`timetable.js:196-205`）；「恢复默认」清本地覆盖再拉学校配置（`timetable.js:208-213`）。

1. `importTimetable` 的入参是 `body.userId`，也就是"导给哪个学生"，不是"导给哪个班/哪个学校"（`CampusController.java:115`）。

## 五、数据表与字段

| 表 | 关键字段 | 用途 | 谁写 |
|---|---|---|---|
| `academic_term` | `school`（VARCHAR 学校名）、`school_id`、`term_label`、`start_date`、`end_date`、`midterm_start`、`midterm_end`、`final_start`、`active`、唯一键 `uk_term(school,term_label)` | 学期锚点 | 管理端 |
| `course_schedule` | `term_id`、`user_id`、`name`、`room`、`day`（0=周一）、`period`（0=第一大节）、`theme`、`week_start`、`week_end`、唯一键 `uk_course(term_id,user_id,day,period,name)` | 课程 | 学生自建 / 管理员 CSV |
| `calendar_event` | `term_id`、`title`、`start_date`、`end_date`、`note` | 校历（**已下线，表与种子仍在**） | 无人写 |

迁移脚本：`backend/src/main/resources/db/module-messages-academics.sql`（含 4 张表 + 演示种子；`academic_term.school_id` 由 `module-multischool-admin.sql` 追加）。

**表里没有的东西：**
- `course_schedule` 与 `academic_term` 之间**没有外键**（`module-messages-academics.sql:30-35` 只有唯一键与普通索引）→ 删学期不会级联，课程变孤儿。
- `academic_term.active` **没有唯一约束**（`:28`），同一学校可以有多条 `active=1`。
- 没有"班级/专业/开课库"任何概念 → 课表只能一个人一个人灌。

## 七、业务规则与边界（什么情况会拒绝、什么情况会兜底）

| 场景 | 现状 | 证据 |
|---|---|---|
| 学校没配学期 | 拒绝：「该学校尚未配置学期，请先在 academic_term 添加当前学期」 | `CampusService.java:40-43`、`:101` |
| 学期日期字段缺失 | 未防御：`date(term.get(key))` 直接 `LocalDate.parse`，null 会 NPE | `CampusService.java:38-39` |
| 现在第几周 | 「本学期周一」到「今天所在周一」的周数 +1，最小 1 | `CampusService.java:46` |
| 请求周次越界 | 夹到 1–60 | `CampusService.java:46` |
| 课程名 | 1–64 字 | `CampusService.java:53-54`、`:112` |
| 星期 | 自建：0–6；导入：认「周一/星期一/1–7」 | `CampusService.java:55-56`、`:135-144` |
| 节次 | 自建：0–9；导入：0–9 | `CampusService.java:57-58`、`:115-116` |
| 周次范围 | 1–60 且 start ≤ end | `CampusService.java:59-62`、`:117-118` |
| 教室 | ≤64 字；导入时空值填"待定"、超长截断 | `CampusService.java:63-64`、`:121` |
| 配色 | 自建：≤16 字；导入：第 7 列任意字符串，**不校验** | `CampusService.java:65-66`、`:123` |
| 同格同名再次提交 | `ON DUPLICATE KEY UPDATE` 覆盖（视为更新） | `CampusMapper.java:120-125` |
| CSV 有任一行错误 | **整批不导**：`imported=0`，只回前 20 条错误 | `CampusService.java:127` |
| CSV 全空 | 拒绝「没有可导入的有效行」 | `CampusService.java:128` |
| `replace=true` | 先 `DELETE` 该学期该用户全部课程，再逐条 upsert | `CampusService.java:129-130` |
| 导入中途抛异常 | **无事务**：已删的删了、已写的写了，留下半份课表 | `CampusService.java:95-134`（无 `@Transactional`） |
| 删学期 | 只删 `academic_term`，课程留着 | `AdminModuleService.java:730-739` |
| 删别人的课 | 拒绝「只能删除自己的课程」 | `CampusService.java:84-87` |
