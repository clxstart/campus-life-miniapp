## 一、这个功能解决什么问题

给小程序一个"陪伴感"入口：一只像素宠物，可喂食、抚摸、签到、换装、派出去做任务带奖励回来。首页右上角「🐾」进的就是它（`pages/index/index.wxml:28-31`、`pages/index/index.js:156-158`）。

商业上它承担两件事：
1. **每日回访**（签到、喂食有次数与时间成本）；
2. **积分消耗与产出**（喂食扣分、衣柜换装扣分、派遣给分、签到给分），与积分体系打通。

**领养是隐式的**：`petOf()` 发现有用户没宠物就直接建一行（`PetMapper.java:18` `INSERT IGNORE INTO user_pet`），没有独立的"领养"接口。

## 三、运营看到的样子（Web 端）

**没有。** 后台 41 条路由里没有任何宠物相关页面（`web/src/router/index.js` 全文无 pet）。能间接影响宠物的只有：

| 页面 | 影响 | 证据 |
|---|---|---|
| 积分任务 | `pet_checkin`、`pet_dispatch` 的开关与日上限 | `web/src/views/PointsTasks.vue`、`module-points-v31.sql:99-102` |
| （无） | 物品价格、任务时长/奖励区间**只能改库** | `module-pet-companion.sql:90-100` 种子 |

所以运营想调"派遣一次给多少分""围巾卖多少分"，必须找研发改 SQL。

## 五、数据表与字段

| 表 | 关键字段 | 用途 | 谁写 |
|---|---|---|---|
| `user_pet` | `level`、`exp`、`hunger`、`mood`、`species`/`tint`/`accessory`/`mood_tag`、`last_decay_at`、`last_feed_at` | 宠物本体与外观 | 服务端惰性建行与衰减 |
| `pet_interaction_log` | `user_id`、`action`、`exp_gain`、`cost_points` | 每日次数统计的依据 | 每次互动写 |
| `pet_item` | `code`、`category`、`part_id`、`price`、`status` | 衣柜商品字典（4 件种子，围巾价 0） | 管理端（无界面） |
| `pet_item_owned` | `user_id`、`item_id`、`equipped` | 拥有/装备关系 | 购买、装备 |
| `pet_task` | `code`、`duration_min`、`reward_min`、`reward_max`、`status` | 派遣任务字典（4 个种子，5–60 分钟） | 管理端（无界面） |
| `pet_dispatch` | `status`（running/claimable/claimed）、`start_at`、`end_at`、`reward` | 派遣记录 | 服务端按时计算 |
| `user_points`/`point_log` | 余额、流水 | 积分收发 | `PointsService` 唯一入口 |

迁移脚本：`module-pet.sql`（`user_pet`/`pet_interaction_log`，幂等建表）、`module-pet-companion.sql`（外观字段 + 物品 + 任务 + 派遣 + 种子）、`module-pet-image.sql`、积分目录 `module-points-v31.sql:99-102`。

## 七、业务规则与边界（什么情况会拒绝、什么情况会兜底）

| 场景 | 现状 | 证据 |
|---|---|---|
| 用户没宠物 | 自动建一行（隐式领养） | `PetMapper.java:18`、`PetService.java:25` |
| 喂食超过 5 次/天 | 「今天已经做过太多次啦」 | `PetService.java:74`、`:79-80` |
| 抚摸超过 10 次/天 | 同上 | `PetService.java:75` |
| 签到超过 1 次/天 | 同上（另有积分域 `bizKey=日期` 二次幂等） | `PetService.java:76`、`:90` |
| 积分不足买/喂 | 「积分不足，去发帖赚积分吧」 | `PetService.java:86`、`PetCompanionService.java:156` |
| 派遣时已有进行中任务 | 「小云已经在路上了，先等等它回来」 | `PetCompanionService.java:255` |
| 派遣未到时间就领取 | 「还不能领取：任务未完成或已被领取」 | `PetCompanionService.java:295-299` |
| 重复领取 | 「这份奖励已经领取过了」 | `PetCompanionService.java:287` |
| 领取不属于自己的派遣 | 「派遣记录不存在或不属于你」 | `PetCompanionService.java:284` |
| 外观传非法值 | 「不支持的 {字段}：{值}」 | `PetCompanionService.java:85-87` |
| 未选宠物就改外观 | 「还没有领养宠物，请先领养」 | `PetCompanionService.java:74-76` |
| 派遣奖励每日上限 | **无**（目录 `dailyCap=0`） | `module-points-v31.sql:102`、`PointsService.java:122` |
