## 一、这个功能解决什么问题

小程序打开的第一屏。用户进来要 30 秒内知道「这个学校有什么可买、可吃、可逛」，而不是面对空列表。

它由四件事组成，本目录只覆盖前三件（第四件归 01 登录与鉴权）：

1. **今日推荐位**：外卖最火 1 条 + 二手最火 1 条，按真实用户行为（浏览/收藏/咨询/下单）加权排序，可「换一批」轮换。
2. **功能入口宫格**：外卖、二手、论坛、兼职、季节活动、学习专区、联想广告位——全部写死在页面里，不走接口。
3. **选学校**：首次进入强制选校，选过之后本地记住，决定后续各列表看哪所学校的数据。
4. **Banner 位**：后端有 CRUD、后台有页面，但小程序首页**没有消费它**（详见 `02-实现现状.md`）。

## 二、用户看到的样子（小程序端）

路径 A（正常进入）：

1. `app.json` 首屏 → `pages/index/index`；
2. `onLoad` 并行发起三件事：`initNavigation()`（纯本地）、`syncSchoolLogo()`、`ensureSchool()`，随后立刻 `loadRecommendations(0)` —— `pages/index/index.js:37-50`；
3. 从未选校 → 弹出底部选择器，且**不允许取消**（`openSchoolPicker(list, true)`，`pages/index/index.js:78`）；只有一所学校时直接选中不打扰（`:72-77`）；
4. 「校园今日推荐」区渲染 `/api/recommend/home` 返回的 `cards`，每张卡带：标签（美食/闲置/求购）、标题、副标题、缩略图、地点、热度文案（`pages/index/index.wxml:151-171`）；
5. 点「换一批」→ `batch+1` 重新请求，`hasMore=false` 时回到第 0 批（`pages/index/index.js:202-206`）；
6. 点卡片 → 走服务端下发的 `card.url`：外卖进 `/pages/food-shop`，二手进 `/pages/market-detail`（`pages/index/index.js:209-213`）。

路径 B（断网）：`utils/api/market.js:377-379` 在**非服务端错误**（网络失败）时返回本地 mock 数据，界面照常显示"热度"，用户看不出是假数据——见 03-09。

路径 C（校园搭子首页，另一个独立页）：`pages/campus-home/campus-home` 是宠物小院，不是首页；底部导航「首页」指向 `pages/index/index`（`components/bottom-nav/index.js:82`）。

## 四、接口清单

以 `@*Mapping` 为准（`backend/src/main/java/com/campuslife/controller/RecommendController.java`）。

| 方法 | 路径 | 权限 | 作用 | 证据 |
|---|---|---|---|---|
| GET | `/api/recommend/home` | 匿名可访问（只做个性化标记） | 首页推荐位：外卖+二手热度榜，支持 `batch` 轮换、`perType` 条数 | `RecommendController.java:19-26` |
| POST | `/api/goods/{id}/favorite` | 登录（写操作） | 收藏/取消收藏二手商品，收藏数按表重算 | `RecommendController.java:29-35` |
| POST | `/api/goods/{id}/view` | 登录（写操作） | 商品浏览量 +1 | `RecommendController.java:38-39` |
| POST | `/api/goods/{id}/contact` | 登录（写操作） | 商品"私聊卖家"计数 +1 | `RecommendController.java:42-43` |
| POST | `/api/shops/{id}/view` | 登录（写操作） | 店铺浏览量 +1 | `RecommendController.java:46-47` |
| GET | `/api/banners` | 匿名只读 | 指定槽位的 Banner 列表 | `ForumController.java:160-162` |
| GET/POST/PUT/DELETE | `/api/admin/banners[/{id}]` | 管理端 token | Banner 增删改查 | `AdminModuleController.java:393-419` |
| GET | `/api/schools` | 匿名只读 | 选学校列表 | `CampusController.java:19-20` |
| GET | `/api/schools/{id}/locations` | 匿名只读 | 发帖选地点（首页选校后可用） | `CampusController.java:22-26` |

关键点：`/api/recommend/home` **没有任何 schoolId 参数**，服务端也无处取用户的学校——这是 03-02 P0 的根因。

## 五、数据表与字段

| 表 | 关键字段 | 用途 | 谁写 |
|---|---|---|---|
| `goods` | `view_count` / `favorite_count` / `contact_count`（新增）、`status`、`audit_status`、`school_id` | 二手商品与被推荐的基础数据 | 发布者写业务字段；`RecommendMapper` 自增三个计数 |
| `shop` | `order_count`（新增，真实下单数）、`view_count`（新增）、`monthly_sales`（平台大盘、非本系统产生）、`school_id` | 外卖店铺热度 | 下单回调写 `order_count`；`/shops/{id}/view` 写 `view_count` |
| `goods_favorite` | `goods_id` + `user_id` 唯一键 | 收藏关系（可跨用户累计） | 用户点收藏 |
| `banner` | `school_id`、`slot`、`sort` | 轮播位配置 | 管理端（页面进不去） |
| `school` | `id`、`name`、`logo` | 选学校与首页 logo | 管理端 |

迁移脚本：`backend/src/main/resources/db/module-hotness.sql`（热度三列 + `goods_favorite` + `idx_goods_hot`）、`module-perf-index.sql`（`idx_goods_school`、`idx_shop_school` 等 10 个索引）。

⚠️ `module-hotness.sql:54` 有一条**给存量商品刷初始浏览量的 UPDATE**：`UPDATE goods SET view_count = 12 WHERE view_count = 0 AND status = 1;`。这是为了让冷启动的推荐位有内容，但它意味着"热度"从第一天起就含有非真实值。

## 七、业务规则与边界（什么情况会拒绝、什么情况会兜底）

| 场景 | 现状 | 证据 |
|---|---|---|
| `perType` 传 0 / 100 | 夹到 1–10 | `RecommendController.java:25` |
| `batch` 传负数 | 夹到 0 | `RecommendController.java:24` |
| 商品/店铺总数为 0 | offset 不取模，避免除零；返回空 `cards` | `RecommendService.java:90-91` |
| 换一批到底 | `hasMore = shopTotal>size \|\| goodsTotal>size`，为 false 时前端回第 0 批 | `RecommendService.java:137`、`pages/index/index.js:204` |
| 收藏查询失败 | 吞异常，星标降级为 false，首页照常返回 | `RecommendService.java:66-72` |
| 匿名访问 | `userId` 缺省回落 1（演示用户），星标按 user 1 算 | `RecommendService.java:84`、`CurrentUser.java:33-35` |
| 未登录调 `/goods/{id}/view` | 401（写方法需 token） | `AuthInterceptor.java:136-137` |
| 缓存满 256 条 | 整体 `clear()`，下一次全部回源 | `RecommendService.java:40` |
| 商品被审核驳回 | `status` 置 0 → 不进推荐；但后台"上架"只改 `status` 不改 `audit_status`，可让驳回商品回到推荐位 | `AuditMapper.java:147`、`AdminModuleMapper.java:373`、`RecommendMapper.java:24` |
