### 未跑（不冒充结论）

| 项 | 为什么没跑 | 补验命令 / 方式 |
|---|---|---|
| 报名→展示全链路真机 | 需要微信开发者工具与真机，且需先修照片上传 | 真机走：banner → 评选页 → 报名 → 上传 → 返回列表看自己 |
| 并发重复投票 | 需要两路并发请求 | `for i in $(seq 1 20); do curl -s -X POST -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' -d '{"userId":1}' http://localhost:8080/api/idol/contestants/1/vote & done; wait` |
| 票数一致性（`vote_count` vs `idol_vote` 行数） | 需要连库 | `SELECT c.id,c.vote_count,(SELECT COUNT(*) FROM idol_vote v WHERE v.contestant_id=c.id) AS real FROM idol_contestant c` |
| 超管/校管权限边界 | 需要两套 token | 用校管 token 打 `GET /api/admin/idol-contestants` 看是否 403 |
| 微信内容安全是否拦违规昵称 | 需配 `CAMPUS_WX_APPID/SECRET`；且 `join()` 根本没调审核 | 配参后提交含违禁词的昵称，预期**仍会成功**（因为无审核调用） |
