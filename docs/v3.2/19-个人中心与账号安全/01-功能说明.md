## 一、这个功能解决什么问题

「我的」是小程序里唯一的**个人数据出口**：用户在这里看自己的资料、地址、收藏、浏览记录、优惠券、黑名单，并在这里做两件不可逆的事——**拉黑**和**注销**。

它同时是三个安全边界所在：

1. **归属边界**：`/api/users/{id}/xxx` 里的 `{id}` 如果被改成别人的，能不能看到别人的收藏/地址/优惠券。
2. **文件边界**：上传的图片分「公开」与「私有」两类，私有类（学生证、身份证、报名材料）必须只有本人和审核员能看。
3. **退出边界**：注销必须真的让账号不可用、让旧 token 失效，并且不能留下可识别到人的信息。

这三条边界只要有一条松了，就不是体验问题，而是个人信息泄露。

## 三、运营看到的样子（Web 端）

1. `#/users` 用户管理：按校/关键词搜用户，看昵称、学校、注册时间、发帖数（`web/src/views/Users.vue`、`AdminModuleController.java:196-203`）。
2. 可改用户头像：`PUT /api/admin/users/{id}/avatar`（`AdminModuleController.java:241-246`），校管只能改本校用户（`AdminModuleService.java:246-251`）。
3. 用户表**没有**「重置用户资料/踢下线/封禁」按钮——`user.status` 只有注销会写 0，管理端无法主动封禁普通用户。这是一个能力缺口（见 03 第五节）。
4. 上传相关：`#/settings`（运营设置）用 `NoImageUpload` 组件上传二维码，走管理端上传接口。

## 七、业务规则与边界

**会拒绝的情况**

1. 路径 `{id}` 与 token 身份不一致 → 403「只能查看自己的数据」（`UserController.java:24-29`）。
2. 未登录访问「我的数据」→ 401（`AuthInterceptor.java:74-92`）。
3. 注销时仍有未完成订单 → 409「还有 N 笔订单未完成」（`UserService.java:122-125`）。
4. 重复注销 → 409「账号已注销」（`UserService.java:120`）。
5. 拉黑自己 → 400「不能拉黑自己」；目标用户不存在 → 400（`UserBlockService.java:68-70`）。
6. 改/删别人的地址 → 按 `id + userId` 双条件查，查不到即「地址不存在」（`UserService.java:84-92, 95-99`）。
7. 上传非图片 / 伪装扩展名 → 400「文件内容不是有效图片」（`UploadService.java:74-79, 118-138`）；超过 5MB → 400。
8. 上传功能被功能开关关闭 → 400 带运营自定义文案（`UploadController.java:22-26`）。

**会放行、但需要知情的情况**

1. **私有图片可被直链访问**：私有文件落在 `<upload root>/private/`（`LocalObjectStorage.java:27, 37`），而 `WebConfig.java:54` 把 `/uploads/**` 映射到 `<upload root>` 整个目录。因此 `/uploads/private/<文件名>` 能直接取到文件。代码注释写的是「不走 `/uploads/**` 静态映射，因此无法被直接访问」（`UploadController.java:49-50`），**与实现不符**。
2. **私有上传接口匿名可用**：`AdminInterceptor.java:30` 对 `/api/admin/upload/private` 在无 token 时直接放行（为商家入驻上传营业执照设计的），限流键是 `private-guest:<IP>`（`UploadController.java:75-78`）。
3. 匿名公开上传：任何人可往公开目录写文件，限流 20/分钟/IP（`UploadController.java:35, 80-82`）。
4. 注销后旧 token 立即失效，但**数据仍在**：帖子/评论/收藏/地址/浏览记录全部保留，只是 `user` 行变了。
5. 拉黑失败时不过滤：`hiddenUserIds` 读库异常时返回空列表并只打 warn（`UserBlockService.java:45-50`），即数据库抖动期间拉黑暂时失效。
6. **活动报名材料走的是公开上传通道。** 小程序的 `uploadImage` 一律 POST 到 `/upload`（`utils/api/market.js:333-357`），报名材料页也用它（`pages/activity-enroll/activity-enroll.js:79-83`），于是材料图片落在公开目录、拿到的是 `/uploads/xxx` 公开 URL。审核员看到的是公开链接，任何拿到该链接的人都能访问。
7. 反馈内容长度：DTO 校验（`FeedbackRequest`），DB 字段 255。
