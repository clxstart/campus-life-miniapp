## 一、这个功能解决什么问题

学生在校内找学习相关的人与信息：课程互助（daike）、论文指导（paper）、就业实习（job）、考研（kaoyan）、考公（kaogong）。

实现方式很关键：**它不是独立业务，是论坛的一个分类视图**。`post` 表加一列 `learn_category`（`module-learn.sql:4-8`），发布/列表/点赞/评论/举报全部复用论坛链路。

## 二、用户看到的样子（小程序端）

路径（浏览）：

1. 首页「学习专区」整卡或多入口 → `/pages/learn/learn?category=daike|paper`（`pages/index/index.js:13-17`、`:151-153`）；
2. 进页读本地已选学校，再 `GET /learn/topics`（主键游标分页，`beforeId`，`pages/learn/learn.js:18-27`）；
3. 分类标签 5 个，来自客户端常量 `utils/learn.js:2-8`；
4. 每类有 `hint/guide/badge/tips` 静态文案（提问建议），空态时可点「看看入门建议」（`learn.js:75`）；
5. 切分类/切学校都会重新拉（`learn.js:27-34`）；分类数量角标**已下线**，接口仍在但页面不再调用（`learn.js:35` 注释）。

路径（发布）：

1. 列表页「发布」→ `/pages/learn-publish`（`app.json:12` 已注册）；
2. 选分类 → 填标题（≤64）+ 正文（≤3000）+ 最多 1 张图 + 可选地点（`pages/learn-publish/learn-publish.js:44-56`）；
3. 提交前**重新读一次**已选学校，没选就拦（`learn-publish.js:51-53`）；
4. 上传图 → `api.publishPost({ learnCategory, schoolId, crossSchool:false, ... })`（`learn-publish.js:59-62`）；
5. 成功后回列表并让列表重载（`learn-publish.js:66-74`）。

路径（互动）：列表里点赞走论坛点赞接口；离线时明确拒绝并提示「离线时暂时无法点赞」（`learn.js:102`）。

| 方法 | 路径 | 权限 | 作用 | 证据 |

| GET | `/api/learn/topics` | 匿名可读（userId 仅用于个性化标记） | 分类话题列表，主键游标分页 | `ForumController.java:29-37` |

## 七、业务规则与边界（什么情况会拒绝、什么情况会兜底）

| 场景 | 现状 | 证据 |
|---|---|---|
| 分类不在白名单 | 拒绝「学习分类不合法」 | `ForumService.java:134` |
| 学习帖设跨校可见 | 拒绝「学习交流仅在所选学校可见」 | `ForumService.java:141` |
| 标题/正文命中敏感词 | 走 `AuditService.checkText`，命中即拒或转人工 | `ForumService.java:136-137` |
| 标题/正文含违规但未命中词库 | 图片存在时 `pending` 转人工；无图时 `passed` 直接上线（fastlane） | `ForumService.java:152-157` |
| 图片未上传成功 | 拒绝「图片未上传成功，请重新选择图片」 | `ForumService.java:135` |
| 未选学校就发布 | 客户端拦「请先回首页选择学校」；服务端再兜一次 | `learn-publish.js:52-53`、`ForumService.java:142` |
| 断网 | 返回空列表 + `offline:true`，UI 显示「网络暂不可用，已保留当前内容」 | `utils/api/learn.js:13-16`、`pages/learn/learn.js:44-45` |
| 断网点赞 | 明确拒绝「离线时暂时无法点赞」 | `pages/learn/learn.js:102` |
| 分类名想改/加类 | 改客户端常量并发版；后端白名单 `LEARN_CATEGORIES` 也要同步改 | `utils/learn.js:2-8`、`ForumService.java:134` |
