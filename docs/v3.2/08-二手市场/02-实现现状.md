## 二、后端：逐条核对

### 2.1 发布与审核

- [✅] **请求体 userId 由 token 覆盖** —— 证据：`backend/src/main/java/com/campuslife/controller/BizController.java:113-115`（`body.put("userId", requireUser(request))`）
- [✅] **标题/价格/描述/成色/分类长度与范围全部服务端校验** —— 证据：`backend/src/main/java/com/campuslife/service/BizService.java:194-208`
- [✅] **图片必须是服务端可访问地址，显式拒绝 `wxfile://` 与 `http://tmp/`** —— 证据：`BizService.java:151-159, 222-228`
- [✅] **文本审核 + 图片异步审核双通道** —— 证据：`BizService.java:229-230`（文本）、`:256`（`scheduleImagesAfterCommit`）
- [✅] **审核状态决定是否可见** —— 证据：`BizService.java:246-250`（`status = passed ? 1 : 0`）、`ModuleMapper.java:23`（列表过滤 `status=1 AND audit_status='passed'`）
- [✅] **商品归属发布者学校** —— 证据：`BizService.java:252`
- [✅] **只允许删除自己的商品（SQL 层双条件）** —— 证据：`backend/src/main/java/com/campuslife/mapper/ModuleMapper.java:81-82`（`DELETE FROM goods WHERE id=#{id} AND user_id=#{userId}`）
- [🟠] **删除是物理删除，不软删** —— 证据：同上。已成交的商品被卖家删掉后，`market_trade` 会指向不存在的 goods（`market_trade` 没有外键）

### 2.2 列表与分页

- [✅] **分页版与不分页版过滤条件一致** —— 证据：`ModuleMapper.java:34-60`（三条 SQL 条件相同，注释明确要求一致）
- [✅] **分页 size 上限 50、page 下限 1** —— 证据：`BizService.java:125-126`
- [✅] **LIKE 通配符转义** —— 证据：`BizService.java:293-295`（兼职搜索共用，二手分类是精确匹配不用 LIKE）
- [🟠] **`mode` 参数非法值静默归一成 1** —— 证据：`BizService.java:113,122`（`mode == 2 ? 2 : 1`）。传 `mode=3` 会返回"出售"，不报错

### 2.3 详情

- [✅] **详情只返回在售且审核通过的商品** —— 证据：`ModuleMapper.java:62-70`（`WHERE g.id=? AND g.status=1 AND g.audit_status='passed'`）
- [✅] **卖家信息只透出 id 与昵称，无手机号** —— 证据：`ModuleMapper.java:66`（`u.id AS sellerId, u.nickname AS sellerNickname`）
- [🔴] **已售出商品（`status=2`）的详情直接 404** —— 证据：同上。后果：买家从收藏/聊天记录点进去看到「物品不存在或已下架」（`BizService.java:186`）

### 2.4 收藏与热度

- [✅] **收藏落库到独立表，计数用子查询重算避免漂移** —— 证据：`backend/src/main/java/com/campuslife/mapper/RecommendMapper.java:67-77`（`UPDATE goods SET favorite_count=(SELECT COUNT(*) FROM goods_favorite f WHERE f.goods_id=#{id})`）
- [🔴] **收藏没有读接口** —— `goods_favorite` 只在 `RecommendMapper` 出现，全仓库无第二个引用（`grep -rn "goods_favorite" backend/src/main/java/` 只命中 `RecommendMapper`）；`GET /api/users/{id}/favorites` 查的是帖子收藏表 —— 证据：`backend/src/main/java/com/campuslife/service/UserService.java:43-45`
- [🟠] **收藏状态前端读的是本地 storage，不读服务端** —— 证据：`pages/market-detail/market-detail.js:30`（`favored: api.isGoodsFavorite(this.id)`）、`utils/api/market.js:119-128`（读写 `wx.getStorageSync('goods_favorites')`）
- [🟠] **无主用户回落到 1 号用户** —— 证据：`backend/src/main/java/com/campuslife/service/RecommendService.java:164`（`Long uid = (userId == null || userId < 1) ? 1L : userId;`）。当前 `POST` 会被 `AuthInterceptor` 拦成 401，所以只在 `campus.auth.enforce=false` 时可达
- [🟠] **咨询数上报无频率限制，可刷热度** —— 证据：`RecommendMapper.java:79-80`（`UPDATE goods SET contact_count = contact_count + 1`），`RecommendController.java:42-43` 无 RateLimiter
- [🟠] **未登录用户浏览上报被 401 拦掉** —— 证据：`backend/src/main/java/com/campuslife/config/AuthInterceptor.java:135-146`（POST 一律要身份，`/api/goods/{id}/view` 不在白名单），前端 `.catch(() => {})` 静默吞（`pages/market-detail/market-detail.js:13`）

### 2.5 成交确认（F10）

- [✅] **买家不能买自己的商品** —— 证据：`backend/src/main/java/com/campuslife/service/MarketTradeService.java:67`
