## 二、后端：逐条核对

- [✅] 趋势 SQL 用 `AND p.school_id = ?` 而非拼接——证据：`AdminModuleMapper.java:32`。

### 2.2 审核台

- [✅] 6 类内容统一 `type` 参数（post/comment/goods/job/chat/circle）——证据：`service/AuditService.java:461-470`。
- [✅] 每类都做校过滤，评论/私信通过 join `user` 表拿 `school_id`——证据：`mapper/AuditMapper.java:60-79`。
- [✅] 驳回必须填原因（服务层校验）——证据：`AuditService.java:428-431`。
- [✅] 恢复（restore）有独立接口——证据：`AdminAuditController.java:55-59`。

- [🟠] 敏感词导入无条数上限、无去重提示、无异步——证据：`AdminAuditController.java:86-92`（`body.get("words")` 直接 `List` 循环）。

### 2.3 操作日志

- [🟠] **只有 2 个控制器写 `admin_log`**：`AdminModuleController`（`log()` 包装 `AdminAuthService.log`）与 `RiderAdminController`。全仓 48 个控制器——证据：`grep -rln "auth.log(\|insertLog(" backend/src/main/java/com/campuslife/controller/` 只返回这两个文件。

- [✅] 日志查询分页并限 size≤100——证据：`AdminAuthController.java:115`。
- [✅] 日志按角色分流（超管全部 / 校管本人）——证据：`AdminAuthController.java:116-118`、`AdminMapper.java:36-53`。

## 六、测试现状

**能跑的命令**

```bash
# 1) 管理端映射数复核
for f in backend/src/main/java/com/campuslife/controller/*.java; do
  grep -q '"/api/admin' $f && echo "$(basename $f) $(grep -cE '@(Get|Post|Put|Delete|Patch)Mapping' $f)"
done

# 2) 审计日志覆盖率（关键指标：应覆盖所有写接口）
grep -rln "auth.log(\|insertLog(" backend/src/main/java/com/campuslife/controller/ | wc -l   # 期望 48，实际 2

# 3) 二次确认覆盖度
grep -rln "confirm(" web/src/views/*.vue | wc -l    # 18
ls web/src/views/*.vue | wc -l                     # 33

# 4) 系统状态接口（需 super/school token）
curl -H "Authorization: Bearer <校管token>" http://127.0.0.1:8080/api/admin/system/overview
```

**本轮执行情况**

| 命令 | 是否执行 | 结果 |
|---|---|---|
| 1) 映射数复核 | ✅ | 19 个控制器 126 处 + 3 个 `/api` 类 7 处 = 133；`AdminModuleController` 48 处（任务书写 49，含类级注解为 49） |
| 2) 审计日志覆盖率 | ✅ | **2 / 48**（`AdminModuleController`、`RiderAdminController`） |
| 3) 二次确认覆盖度 | ✅ | **18 / 33** 视图 |
| 4) 系统状态接口 | ❌ 未执行 | 无运行中后端 |
| 起服务点页面 | ❌ 未执行 | 台账未登记管理端页面走查 |

**结论**：管理端**没有任何控制器层测试**——29 个测试类（实录 `find backend/src/test -name "*Test.java"`，台账第二节记 28，差额来自取材后仓库仍在改动）里只有 `AdminPaymentServiceTest`、`AdminTokenRevocationTest` 两个与管理端相关，且都测服务/配置层，没有一个 MockMvc 用例去验证「校管调这个接口会 403」。也没有实跑记录。本功能所有 ✅ 都是读码结论。
