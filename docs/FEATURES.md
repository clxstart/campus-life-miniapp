## 五、已实现的底层能力

| 能力 | 实现方式 |
|---|---|
| **登录鉴权** | 微信 code2session 换 JWT（HS384，7天），未配 AppID 时自动降级开发登录 |
| **图片上传** | 服务端存储，5MB 上限，仅 jpg/png/gif/webp，服务端生成文件名防路径穿越 |
| **推荐算法** | `(赞×3 + 评论×5 + 浏览×1) × 兴趣加权 × 时效衰减`，SQL 内排序 |
| **离线兜底** | 后端不可用时静默退回本地 mock，页面顶部显示「演示数据」角标 |
| **写接口不兜底** | 服务端业务错误（拒单等）必须抛给用户，只有网络失败才降级 |
| **课表导入** | 管理员 CSV 批量导入，任一行有错则整批拒绝并返回行号 |
| **全局演示提示** | 按接口记录失败，一个接口成功不会掩盖其他接口的离线状态 |

## 七、如何运行

### 前端
1. 微信开发者工具 → 导入项目 → 选择项目根目录
2. AppID 保持 `touristappid`
3. 点「编译」

### 后端
```bash
# 1. 建库（按顺序，共 28 张表）
mysql -u root -p < backend/src/main/resources/db/schema.sql
mysql -u root -p < backend/src/main/resources/db/module-messages-academics.sql
mysql -u root -p < backend/src/main/resources/db/module-circles.sql
mysql -u root -p < backend/src/main/resources/db/module-auth.sql

# 2. 改 application.yml 的数据库密码
# 3. 启动（JDK 23+ 需要禁用全局 jdk-1.8 profile）
cd backend
mvn spring-boot:run -P '!jdk-1.8'
```

### 验证
```bash
node --test tests/regression.test.js    # 22 项行为测试
python tests/validate_project.py        # 静态工程检查
```

> **后端不启动时，小程序全部功能依然可用**，数据来自本地 mock，页面会显示「演示数据」提示。
