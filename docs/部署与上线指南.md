# 部署与上线指南

> 编写时间：2026-10-27
> 用途：把项目从「本机能跑」变成「线上能跑」。本文接替已被清理的旧部署文档，并补回丢失的鉴权规则。
> 环境变量模板：根目录 `.env.example`（照抄改值即可）

---

## 一、三个 profile 的分工

配置按环境拆开，**不要改 `application.yml` 里的密钥**：

| 文件 | 用途 | 特点 |
|---|---|---|
| `application.yml` | 与环境无关的默认值 | 端口、连接池、鉴权开关、上传限制 |
| `application-dev.yml` | 本机开发 | 127.0.0.1 数据库、演示密码、模拟支付开、允许本机跨域 |
| `application-prod.yml` | 生产 | **敏感项全部无默认值**，缺环境变量直接启动失败 |

启动时指定 profile：

```bash
# 本机（默认就是 dev，可省略）
mvn spring-boot:run

# 生产
java -jar campus-life-api.jar --spring.profiles.active=prod
```

> `prod` 下缺 `CAMPUS_JWT_SECRET` 会报 `Could not resolve placeholder` 并中止启动 —— **这是故意的**，避免用开发默认密钥上线。

## 二、必需环境变量

完整模板见 `.env.example`。核心这些：

### 数据库

```bash
export DB_URL='jdbc:mysql://127.0.0.1:3306/campus_life?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&useSSL=false'
export DB_USERNAME='campus_user'      # 不要用 root
export DB_PASSWORD='<强密码>'
```

### 认证密钥

```bash
export CAMPUS_JWT_SECRET='<32位以上随机串>'   # 生成：openssl rand -base64 48
```

> 不配的话 `prod` 直接启动失败。dev 有默认值但会打 WARN。

### 微信小程序（配了才会关闭开发登录）

```bash
export CAMPUS_WX_APPID='wx...'
export CAMPUS_WX_SECRET='...'
```

> **重要**：`CAMPUS_WX_APPID` 为空时 `/api/auth/dev-login` 是开着的（默认只允许 1 号演示账号）。线上必须配真实 AppID，否则任何人都能以演示账号进入。

### 跨域与上传

```bash
export CAMPUS_WEB_ORIGINS='https://admin.你的域名.com'   # 管理端跨域白名单，逗号分隔
export CAMPUS_UPLOAD_BASE_URL='https://api.你的域名.com' # 上传图片对外基址
```

> 不配 `CAMPUS_WEB_ORIGINS` 就只有 localhost 能访问管理端接口。

### 微信支付（不接支付可全部留空）

```bash
export WXPAY_ENABLED='true'
export WXPAY_APP_ID='wx...'
export WXPAY_MCH_ID='...'
export WXPAY_CERT_SERIAL_NO='...'
export WXPAY_API_V3_KEY='<32位>'
export WXPAY_PRIVATE_KEY_PATH='/opt/campus/certs/apiclient_key.pem'
export WXPAY_NOTIFY_URL='https://api.你的域名.com/api/pay/notify'
export WXPAY_REFUND_NOTIFY_URL='https://api.你的域名.com/api/pay/refund/notify'
```

详细办理流程见 `docs/真实支付接入指南-五条件.md`。

## 三、接口鉴权规则（上线必读）

> 这一节原本在已删除的旧文档 §3.4 里，这里补回。

### 3.1 三套独立身份，token 互不通用

| 身份 | 登录接口 | 管辖路径 | 拦截器 |
|---|---|---|---|
| 小程序用户 | `/api/auth/login` 或 `/api/auth/dev-login` | `/api/**` 用户侧 | `AuthInterceptor` |
| 管理员 | `/api/admin/login` | `/api/admin/**` | `AdminInterceptor` |
| 商家 | 同一登录接口（role=merchant） | `/api/merchant/**` | `AdminInterceptor` |
| 骑手 | 同一登录接口（role=rider） | `/api/rider/**` | `RiderInterceptor` |

### 3.2 哪些接口必须带 token

| 请求类型 | 是否必须 |
|---|---|
| **写操作**（POST/PUT/DELETE，`/api/**`） | ✅ 必须，无 token 一律 401 |
| **私有读**：`/api/conversations`、`/api/notifications`、`/api/timetable`、`/api/pet`、`/api/circle-messages`、`/api/users/{id}/` 下的 favorites/views/coupons/addresses/publish-count | ✅ 必须 |
| **公开读**：帖子流、搜索、学校、圈子、商家、二手、兼职、活动、推荐、banners | ❌ 不需要（匿名可读，userId 仅用于"我点过赞吗"这类个性化） |
| **白名单**（永不校验）：`/api/auth/**`、`/api/admin/login`、`/api/merchant/apply`、`/api/pay/notify`、`/api/pay/refund/notify`、`/api/ai/**`、`/api/upload` | ❌ 不需要 |

### 3.3 身份以 token 为准

- 控制器统一用 `CurrentUser` 取身份，**不信任**客户端传的 `userId`
- 伪造别人的 `userId` 只会记在自己名下
- `/api/users/{id}/favorites` 这类接口会校验路径 `{id}` 必须等于登录用户，不一致返回 403

### 3.4 三个开关（默认值都是安全的）

| 环境变量 | 默认 | 作用 | 生产建议 |
|---|---|---|---|
| `CAMPUS_AUTH_ENFORCE` | `true` | 是否强制校验 token。设 false 会退回"谁传 userId 就是谁" | **必须 true** |
| `CAMPUS_PAY_SIMULATE` | `true`(dev) / `false`(prod) | 支付未启用时是否允许模拟支付 | prod 下代码强制拒绝 |
| `CAMPUS_DEV_LOGIN_ANY_USER` | `false` | 开发登录是否可登任意账号 | **必须 false**；配了真实 AppID 后整个 dev-login 关闭 |

### 3.5 上线自测（4 条 curl）

```bash
# 1. 匿名打管理端 → 应 401
curl -s -o /dev/null -w '%{http_code}\n' https://api.你的域名.com/api/admin/users

# 2. 匿名打私有读 → 应 401
curl -s -o /dev/null -w '%{http_code}\n' https://api.你的域名.com/api/conversations

# 3. 匿名打公开读 → 应 200
curl -s -o /dev/null -w '%{http_code}\n' 'https://api.你的域名.com/api/posts?page=1&size=1'

# 4. 开发登录应已关闭 → 应 400「已配置微信登录，开发登录不可用」
curl -s -X POST https://api.你的域名.com/api/auth/dev-login \
  -H 'content-type: application/json' -d '{"userId":1}'
```

## 四、多校隔离配置

平台方管多所学校，上线前必须确认：

| 事项 | 检查方式 |
|---|---|
| 每所学校在 `school` 表里有记录且 `status=1` | `SELECT id,name,status FROM school` |
| 每所学校有**激活的学期** | `SELECT school_id, COUNT(*) FROM academic_term WHERE active=1 GROUP BY school_id` |
| 学校的 `school_id` 与用户、内容数据对得上 | 抽查 `SELECT school_id, COUNT(*) FROM post GROUP BY school_id` |

> **最容易漏的**：新学校开通时没人自动建学期，该校学生打开课表会报「该学校尚未配置学期」。开通新校的流程里必须包含"建学期并设为当前学期"。

超管可在管理端切学校看数据；校管的 token 里带 `schoolId`，只能看本校（传别校返回 403）。

## 五、部署步骤（Nginx + 单机）

### 5.1 打包

```bash
cd backend
mvn clean package -DskipTests
# 产物：target/campus-life-api-1.0.0.jar
```

### 5.2 管理端打包

```bash
cd web
pnpm install
pnpm build
# 产物：web/dist/（纯静态文件）
```

### 5.3 Nginx 配置

```nginx
server {
    listen 443 ssl;
    server_name api.你的域名.com;

    ssl_certificate     /etc/letsencrypt/live/api.你的域名.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.你的域名.com/privkey.pem;

    # 后端 API
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 上传文件
    location /uploads/ {
        proxy_pass http://127.0.0.1:8080;
    }

    # 圈子群聊 WebSocket
    location /ws/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 3600s;
    }
}

# 管理端（可以同域不同端口，或独立域名）
server {
    listen 443 ssl;
    server_name admin.你的域名.com;

    ssl_certificate     /etc/letsencrypt/live/admin.你的域名.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/admin.你的域名.com/privkey.pem;

    root /opt/campus/web;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;   # hash 路由其实不需要，但留着无害
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
    }
}
```

> **WebSocket 那段的 `proxy_read_timeout 3600s` 必须加**，否则群聊连接会被 Nginx 60 秒掐断。

### 5.4 启动脚本

```bash
#!/bin/bash
cd /opt/campus
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk
# 环境变量从 .env.production 加载
set -a; source /opt/campus/.env.production; set +a

nohup $JAVA_HOME/bin/java \
  -Xms1536m -Xmx1536m \
  -XX:+UseG1GC -XX:MaxGCPauseMillis=200 \
  -XX:+HeapDumpOnOutOfMemoryError \
  -XX:HeapDumpPath=/var/log/campus/heap.hprof \
  -jar campus-life-api.jar \
  --spring.profiles.active=prod \
  > /var/log/campus/app.log 2>&1 &

echo $! > /var/log/campus/app.pid
```

### 5.5 小程序端切换

```js
// utils/config.js
const ENV = 'prod'   // 从 'dev' 改成 'prod'

const ENDPOINTS = {
  prod: {
    api: 'https://api.你的域名.com/api',
    asset: 'https://api.你的域名.com'
  }
}
```

然后到微信公众平台 → 开发管理 → 服务器域名，配置：

```
request 合法域名：https://api.你的域名.com
uploadFile 合法域名：https://api.你的域名.com
downloadFile 合法域名：https://api.你的域名.com
```

## 六、上线检查清单

### 部署前

- [ ] 数据库脚本已执行（`schema.sql` + 需要的 `module-*.sql` + `module-activity-enroll.sql`）
- [ ] 索引迁移已执行（`module-perf-index.sql`）
- [ ] 数据库账号改为非 root
- [ ] `CAMPUS_JWT_SECRET` 是随机串（不是仓库里的 dev 默认值）
- [ ] `CAMPUS_WX_APPID` 已配真实 AppID（否则 dev-login 开着）
- [ ] `CAMPUS_WEB_ORIGINS` 已配管理端域名
- [ ] `CAMPUS_UPLOAD_BASE_URL` 已配真实域名
- [ ] 启动参数带 `--spring.profiles.active=prod`
- [ ] JVM 参数已加（`-Xms1536m -Xmx1536m`）

- [ ] 后端启动无报错，日志里**没有** `模拟支付生效`

- [ ] 第三节 4 条 curl 全部符合预期
- [ ] 管理端能登录（`CAMPUS_WEB_ORIGINS` 配对）
- [ ] 小程序能拉到数据（域名白名单配好）
- [ ] 圈子群聊能连上（WebSocket 反代配置对）

## 七、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 启动报 `Could not resolve placeholder 'CAMPUS_JWT_SECRET'` | prod profile 缺环境变量 | 补上，或确认 `set -a; source .env` 生效 |
| 管理端能打开但接口全 403 | `CAMPUS_WEB_ORIGINS` 没配管理端域名 | 加上，逗号分隔 |
| 管理端登录后立刻掉线 | 跨域没带 `Authorization` 预检 | 确认 Nginx 透传 `Host`，CORS 已配 |
| 小程序真机所有接口失败 | 服务器域名白名单没配 | 微信后台配置三个域名 |
| 群聊连上 60 秒就断 | Nginx 缺 `proxy_read_timeout` | 见 5.3 配置 |
| 上传成功但图片裂开 | `CAMPUS_UPLOAD_BASE_URL` 还是 127.0.0.1 | 改成公网域名 |
| 学生打开课表报「尚未配置学期」 | 该校没建激活学期 | 管理端教务管理里建并设为当前学期 |
